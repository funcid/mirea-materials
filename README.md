# mirea-materials

Материалы учебных курсов МИРЭА.

## Курсы

### [java-course](java-course/)

Gradle-монорепозиторий практикума Java (Java 21).

| Модуль | Тема |
| --- | --- |
| `01-language-constructs` | Языковые конструкции: примитивы, `String`, `Math`, `if`/`for`, ввод-вывод. Калькулятор `+ - * /` |
| `02-oop` | Массивы: binary search, два указателя, sliding window |
| `03-classes` | Классы, интерфейсы, контракты: счёт, начисление/списание |
| `04-interfaces-exceptions` | Интерфейсы. Исключения. Отладка |
| `05-collections` | Коллекции |
| `06-io-concurrency` | Ввод-вывод. Многопоточность |
| `07-jdbc-orm` | Базы данных. ORM |
| `08-build-javafx` | Сборка. JavaFX |
| `09-spring` | Spring Framework |
| `10-rest` | RESTful API |
| `11-thymeleaf` | Thymeleaf |
| `12-testing-javadoc` | Тестирование. Javadoc |
