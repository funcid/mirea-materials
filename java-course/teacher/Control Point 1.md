### Задание

Проектируем Яндекс Сервисы (A -> B):

Сущности (class): 
1. Position (double x, y)
2. Order (str: название заказа, Position: откуда, Position: куда)

Варианты доставки (interface CalculateOrderUseCase):
1. Курьером посылку: 1 метр = 1.5 рублей, но не дальше 100 метров (ошибка)
2. Из ресторана еду: 120 рублей + 1 метр = 0.5 рублей, но не дальше 1000 метров
3. Экспресс Сервис: первый метр 0.1 руб. каждый следующий на 0.1 руб. больше
4. Режим "Совместно": общая стоимость 1000 рублей, каждый новый 
расчет делит цена пропорционально длине маршрута в квадрате, пример:
1 расчет = 1000 рублей, 2 равных пути = 500 рублей каждый и тд.

Критерии:
1. Сделано 3 реализации = удовл.
2. 3 реализации + выписаны вопросы и авторы ответов
(ИИ, интернет, материалы, коллеги) = хорошо.
3. 3/4 реализации + выписаны *интересные вопросы и авторы 
ответов из разных источников
