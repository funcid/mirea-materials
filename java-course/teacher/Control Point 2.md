# Контрольная точка 2

Тема: коллекции, HttpClient, синхронизация  
Время: ~80 минут  
Язык: Java 11+  
Базовый URL: `https://exam.funcfund.ru`

Формат ответов: `text/plain` (не JSON).  
Авторизация после регистрации: заголовок `X-Token: <token>`.

Успех этапа — ответ `OK`. Типичные ошибки: `WRONG`, `NEED_STAGE_N`, `TOO_SEQUENTIAL`, `MISSING_TOKEN`, `BAD_TOKEN`.

---

## 0. Регистрация

`POST /api/register` — тело: ваше ФИО одной строкой.

Ответ — две строки:
1. `token`
2. `seed` (целое число)

Дальше во все запросы добавляйте `X-Token`.

---

## 1. Манифест (Set / уникальность)

`GET /api/manifest` — строки вида `id;zone;weight;priority` (в списке есть дубликаты `id`).

`POST /api/manifest/check` — тело: `uniqueCount;firstDuplicateId`

- `uniqueCount` — число уникальных id  
- `firstDuplicateId` — id первого повтора при обходе сверху вниз

---

## 2. Зоны (Map / подсчёт)

`GET /api/zones` → `POST /api/zones/check`

Тело: `zone;count` — зона с максимальным числом посылок.  
При равенстве счётчиков берите лексикографически большую букву зоны.

---

## 3. Приоритет (сортировка)

`GET /api/priority` → `POST /api/priority/check`

Тело: пять id через `;` — топ-5 уникальных посылок.  
Ключ сортировки: (−priority, weight, id). Для дубликатов id берётся первое вхождение.

---

## 4. Диспетчер

`POST /api/dispatch`

Тело: `ans1|ans2|ans3` — ответы этапов 1–3 через `|`.

---

## 5. Дорожки (HttpClient / параллель)

`GET /api/lanes/info` — число дорожек N.  
`GET /api/lanes/{i}` для `i = 0 .. N-1` — целое на дорожке (ответ намеренно медленный).  
`POST /api/lanes/check` — тело: `sum;max`.

Имеет смысл запрашивать дорожки параллельно.

---

## 6. Конвейер (последовательное чтение)

Пока `GET /api/belt/next` не вернёт `DONE` — читайте id по одному.

`POST /api/belt/check` — тело: `count;id0;id1;...` (все id в порядке получения).

---

## 7. Счётчик (синхронизация / волна)

1. `POST /api/counter/reset` — открывает окно волны (~2.5 с), ответ `WAVE_OPEN`.
2. За окно сделайте **ровно 20** запросов `POST /api/counter/inc` с **перекрытием ≥ 8** одновременных запросов.  
   Последовательный цикл не засчитывается (`TOO_SEQUENTIAL`).
3. `GET /api/counter` — текущее значение.
4. `POST /api/counter/check` — тело: `20`.

---

## 8. Пломба

`POST /api/seal`

Тело — ответы этапов 1–7 через `|` в порядке:  
`манифест|зоны|приоритет|диспетчер|дорожки|конвейер|счётчик`
